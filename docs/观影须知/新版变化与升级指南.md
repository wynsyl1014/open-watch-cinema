# 新版变化与升级指南

这篇指南写给已经用过旧版 Open Watch Cinema 的老观众。对照的是 [GitHub 公开版（`6154eec`）](https://github.com/wynsyl1014/open-watch-cinema/tree/6154eec6ef8f8d2a1831169b2f54952ccab71bea)——也就是英文界面、附带旧版《使用说明（给观众）》的那一版。两版的 `package.json` 版本号都标为 `0.5.0`，如果不确定自己用的是哪一版，对照提交号就能确认。

## 新版有哪些变化

- **全中文界面，片库更好打理**：界面全面中文化，银幕下方换成了清爽的图标工具栏和票根式操作区，影院设置、聊天和往期放映各有独立入口。片库支持直接导入影片、建合集、批量整理影片与字幕，还能按单片或整个合集设好跳过片头、片尾和片中片段。想快速认清每个新图标，看 [按钮速查](观影指南.md#按钮速查)。
- **AI 看得更清楚，也能“听”到声音**：新版观影包提供经济、均衡、完整三档分镜，还可以用本机模型生成环境声和音乐描述。准备到起步缓冲就能先开房看片，剩下的部分会在后台继续跑。三档效果对比见 [观影包画质参考](画质参考.md)。
- **支持续看、快捷互动与共用「小本本」**：同一部片下次重开房间时，可以直接接着上次结束的位置继续看。聊天气泡上的电影时间点一下就能跳回那一幕；输入框旁新增了快捷消息和零食碰杯等轻互动。每部片还有一本和 AI 共用的「小本本」，跨场次保存人物（含小传和外貌特征）、关系图、剧情时间线、疑问与随记。单场聊天和整部片的手记都可以导出成离线 HTML 或纯文本。详见 [观影指南](观影指南.md)。
- **AI 多了自动跟片方式**：除了原本的本地 stdio MCP，现在还支持用本机 Codex（App Server）或 ChatGPT 影院卡片自动按进度跟片。继续用普通 MCP 的话，可以直接在影院设置里一键复制配置和开场提示词。银幕下方的「AI 连接」还能随时查看每位 AI 读到了哪里、回看工具返回的文字和分镜。详见 [工具准备](../README.md#工具准备)。

## 从旧版升级

按下面 5 步操作，旧影片、字幕和往期聊天都能平滑带到新版：

### 1. 先关掉旧影院，备份整份本机数据

等正在进行的影片准备任务跑完，再关掉旧版的服务终端。把整个 `local-data` 文件夹备份到项目目录外面（里面包含原片、字幕、`ai-packages` 观影包和旧 SQLite 数据库）。如果你以前用 `LOCAL_DATA_ROOT` 指定过别的数据目录，就备份那个实际目录。

### 2. 用新版程序接手原来的数据

用新版完整源码更新程序。如果把新版解压到了一个新文件夹，在**第一次启动前**把旧的整套数据放进新版的 `local-data`（保持影片文件名、相对路径和修改时间不变）；原本用自定义数据目录的话，让新版继续指向同一个目录即可。

> 如果手头同时有新旧两套数据，建议先放在独立目录里核对，避免同名数据库或观影包互相覆盖。

### 3. 按需要核对本机依赖

- **日常播片**：继续需要 Node.js 24 或更新版本，以及 FFmpeg（含 FFprobe）。
- **准备新版分镜**：确认已有的 Python 3.11+ 环境装有 OpenCV 4.10–4.x 和 NumPy，兼容就可以直接复用。
- **可选声音描述**：单独使用 64 位 Python 3.10.x 和 CoNeTTE，想让 AI 读到环境声和配乐时再装。

安装脚本都支持先加 `--plan` 预览会沿用哪些环境、补装哪些工具，详见 [安装与排错](../工具准备/安装与排错.md)。

### 4. 启动新版，先抽查一部看过的片

旧版放在根目录的启动脚本，现在整理到了 `Windows/start.bat` 和 `macOS/start.command`（以前建过桌面快捷方式的话，记得改一下指向）。

第一次启动新版时，影院会自动给旧数据库做一份校验过的备份，再迁移到 `local-data/影院记录/open-watch-cinema.sqlite`，同时把原片、字幕和观影包按影片归档。打开网页后，可以先抽查一部以前看过的片：
- 在片库确认影片和字幕都在；
- 在「往期放映」确认旧聊天、署名和上次结束位置都正常。

如果启动时提示检测到两份数据库，先别急着操作，核对一下数据目录和第一步做的完整备份。

> **需要回退旧版时**：先关掉新版，用旧程序打开第一步备份的整套数据即可。注意 `影院记录/迁移前备份.sqlite` 里只保存了数据库记录，不包含影片和观影包文件，详见 [本机数据、备份和恢复](观影指南.md#本机数据备份和恢复)。

### 5. 需要新版分镜时，再升级对应影片的观影包

旧观影包在片卡上会显示「升级」，点开后会默认预选原来的对白轨和档位（旧包没记档位时默认选均衡）。

- 新包完整生成并校验通过后才会切换，中途失败会保留原包，不会把旧的弄坏。
- 升级只重做 AI 观影资料，原片、字幕和往期放映记录都不受影响。
- 没装声音模型时，首次沿用默认声音设置也可以先升级画面和对白，以后装好模型再补声音。详见 [升级旧观影包](观影指南.md#升级旧观影包)。

## 重新连接原来的 AI

- **继续用普通 MCP 客户端**：打开新版「影院设置 → 连接 AI → MCP 客户端」，重新复制配置并更新客户端里的路径，然后刷新/重启客户端。新版把「回查历史」和「控制影院」拆成了两个可单独勾选的权限；如果你以前自己写过开场提示词或脚本，注意对照新工具名更新（例如旧版的 `cinema_get_frame` 现在已改为 `cinema_inspect_frame`）。详见 [MCP 客户端接入](../工具准备/MCP%20客户端接入.md) · [MCP 技术参考](../开发须知/MCP%20技术参考.md)。
- **想试试新的自动跟片**：按你平时用的工具直接看对应配置即可——[ChatGPT 工具配置](../工具准备/ChatGPT%20工具配置.md) · [Codex App Server](../工具准备/Codex%20App%20Server.md)。

## 让 AI 帮你完成升级

如果你平时在用 Codex、Claude Code、Antigravity、Cursor 这类可以操作本机文件和终端的 AI 助手，不想自己一步步搬文件和查依赖，可以直接把下面这段话复制发给它（按实际情况填好路径，或者让它先帮你找目录）：

```text
请先完整阅读当前仓库里的 docs/观影须知/新版变化与升级指南.md 和 docs/工具准备/安装与排错.md，然后帮我把本机的旧版 Open Watch Cinema 安全升级到新版。

我的旧版目录在：<填旧版路径，不知道就帮我找>
我的新版目录在：<填新版路径，或原地更新当前目录>
是否自定义过 LOCAL_DATA_ROOT：<没设过 / 填实际路径>

请严格按以下顺序和安全规则执行，关键步骤前先向我汇报并等我确认：
1. 先只读检查：确认旧版影院服务是否仍在运行（如 server.mjs 或 4182 端口）、旧数据目录（local-data 或 LOCAL_DATA_ROOT）里的原片/字幕/ai-packages/open-watch-cinema.sqlite 现状，以及目标磁盘剩余空间是否足够做完整备份。
2. 停服务并备份：提醒我确认没有进行中的观影包任务后再关闭旧服务；把整个旧数据目录完整复制到项目目录之外的带日期备份文件夹，保留文件名、相对路径和修改时间。不要删除旧目录或任何原文件。
3. 衔接数据：在首次启动新版前，把旧数据按原结构放到新版对应的数据目录（或继续指向原 LOCAL_DATA_ROOT）。如果同时发现旧版根目录数据库和「影院记录/open-watch-cinema.sqlite」，立刻停下让我核对，绝不覆盖。
4. 预览依赖：根据我的系统运行 bash macOS/setup-all.command --plan 或 .\Windows\setup-all.bat --plan，把会沿用和需要补装的项列给我看，确认我要不要装声音模型（CoNeTTE）后再执行安装。
5. 启动与验收：用新路径（macOS/start.command 或 Windows/start.bat）启动新版，核对服务正常并把浏览器地址告诉我，让我检查片库、字幕和「往期放映」里的旧记录；不要替我批量重做旧观影包，留给我在片卡按需点「升级」。
6. 收尾提醒：提醒我把旧的启动快捷方式改到新路径；如果我用的是 MCP 客户端，帮我核对并更新客户端配置路径，同时提醒我新版把历史回查（--with-history）和影院控制（--with-control）拆成了可选项，且旧工具 cinema_get_frame 已改为 cinema_inspect_frame。
```

> **安全边界**：无论自己升级还是让 AI 帮忙，升级期间都不要删掉旧版目录和项目外备份，等在新版里确认片库、字幕和往期放映都完整无误后再决定是否清理。

## 2026-11-12：动画角色候选局部实验

Windows、本地 CPU 单线程、OpenCV 4.14.0，沿用本地动画的 60–64 秒五张图片，原始 1920×1080，检测前缩至 640×360。仅处理局部图片副本，不修改原片、观影包、房间或正常准备链。三个独立 Python 进程顺序运行，系统文件缓存未清空；以下耗时不含 FFmpeg 抽帧、Python 启动和模块导入。

- 模型加载 73.7–81.9 ms。
- 每进程首次找脸 16.8–26.4 ms，其后单帧找脸 12.6–18.1 ms。
- 首次对齐及特征提取 53.3–55.5 ms，其后每张脸 21.6–25.9 ms。
- 第一轮首次有参考图的相似比较约 2.4 ms，其后比较约 0.03 ms（最多三个先前参考区域）。
- 五张图片中的一张物件特写无检出，其余四张各检出一张脸。背向镜头的头部未标为正脸。
- 连续三帧红发角色的相似分数为 0.877–0.940；紫发角色与前者为 0.455–0.487。分数不是概率，实验没有设置自动身份归并阈值。

仅与电影时间更早的图比较，不赋角色名，不储存特征向量。需继续验证更多镜头、遮挡和画风，再决定候选筛选规则。当前还没有接入人物笔记或正常 tick。

模型来自 [OpenCV Zoo](https://github.com/opencv/opencv_zoo/tree/48b10fa505aeb51fbd127fc60a5c660040e823b7)：YuNet 2023mar 为 232,589 字节，SFace FP32 2021dec 为 38,696,353 字节，合计约 37.1 MiB。固定提交的 Git LFS SHA-256 与实际文件一致；许可证及来源清单随本地模型保存。该实验功能现已从主程序中移除。

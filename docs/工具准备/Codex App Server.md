# Codex App Server

影院可以让本机 Codex 自动陪你看电影。影片播放时，影院按进度把准备好的分镜、对白和可用的声音描述送进这场放映的 Codex 聊天。你在影院房间里发消息、看回复，也可以一起写手记。

## 第一次连接

1. [启动影院](../观影须知/观影指南.md#启动影院)，点银幕旁的齿轮。在「影院设置 → 名字与档案」选这次一起看的 AI。没有档案时点「添加 AI」。这里选的是影院里的署名。
2. 打开「影院设置 → 连接 AI → 自动观影」，将「自动连接方式」选为 Codex App Server。在「ChatGPT 账号」下选择「沿用本机 Codex 登录」（默认）。想为影院单独登录时，选「使用影院独立登录」。接着点「读取账号与模型」。如果影院提示缺少本机 Codex 或版本需要更新，展开「本机安装与配置」，复制安装命令到终端执行，再回来读取。若设置页提示缺少 Watch Bridge，请从本仓库的 [`watch-bridge` 分支](https://github.com/wynsyl1014/open-watch-cinema/tree/watch-bridge) 获取完整的 `watch-bridge/` 放到影院根目录，与 `mcp/` 并列。
3. 如果还未登录，点「登录 ChatGPT」，再点「打开 ChatGPT 登录页」，在浏览器里完成 Codex 发起的官方登录流程，回到影院等账号状态更新。
4. 在「观影模型」选择支持画面的模型，或保留「Codex 默认模型」。打开「Codex 观影模式」，点「保存 Codex 设置」。

### 用哪个账号模式

| 设置项 | 这场放映用到的配置 |
| --- | --- |
| 沿用本机 Codex 登录 | 使用本机 Codex 的 ChatGPT 登录，以及影院聊天目录中生效的权限和审批设置。其他已配置的插件与 MCP 接入沿用本机配置。影院自己的工具使用这场放映的连接。已装 Codex 桌面端时，影院首次保存新放映聊天后会尝试打开 `cinema` 工作区。 |
| 使用影院独立登录 | 在影院数据目录单独保存 ChatGPT 登录和放映聊天。日常 Codex 的插件和 MCP 配置不会自动带进来。放映使用只读沙箱，审批策略为 `never`。 |

两种模式都通过本机 Codex 登录 ChatGPT。影院窗口没有手动审批入口。默认观影指令允许 Codex 自然地开口和回应，也可以安静看电影。平时希望 Codex 怎样陪你看，可在「观影项目提示词」编辑「项目指令（AGENTS.md）」。其中的 `{{viewerName}}` 会替换为「名字与档案」里的观众昵称，留空时用「观众」。账号模式、模型和项目指令的改动从下一场生效。

## 开房和跟片

1. 在片库导入影片，试播后点「确认可播放」。点「准备观影包」，选对白和分镜，等起步缓冲就绪。导入、字幕和试播的操作见[观影指南](../观影须知/观影指南.md)。
2. 点「开启房间」。「本场开场白」选填。首次开房时有开场白就点「保存并开房」，留空点「开房」。开房后影院自动连接 Codex，为这场放映建一条以片名和开房时间命名的聊天。连接就绪后，银幕下方的「AI 连接」显示档案名，暂停时显示「在线 · 影片暂停中」。
3. 按播放后，影院开始定时送片，默认按影片进度每过 6 秒取一次新资料。需要调整时，在「连接 AI → 自动观影」保存「连续观影间隔」，本场下一次跟片即使用新间隔。开场白随第一批播放资料送达。
4. 在房间聊天框发消息。影片暂停时，发一条消息也能叫 Codex 来聊，普通的定时跟片等到恢复播放。Codex 通过 `cinema_post_message` 发到房间的回复会显示在影院聊天框。「AI 连接」还能查看跟片进度和实际交付内容。看完点「结束房间」，这场放映的自动跟片随即停止。

## 续看同一部影片

上一场结束后，再开同一部影片，有进度时可点「从 14:25 继续」回到对应位置，也可以点「从头看」。两种选择都开启新房间，播放器停在所选位置，按播放开始。选续看时，Codex 在第一批播放资料前收到续看时间和这部影片的共用手记。如果写了本场开场白，它排在最前。播放前发在房间里的普通消息照常送达。

重连仍开放的房间会接回这场放映的 Codex 聊天。已经送达的开场白和续看手记会留在原聊天里。

想从自己正在使用的 Codex 聊天或其他支持本地 stdio MCP 的客户端主动跟片，可用[「MCP 客户端」连接方式](MCP%20客户端接入.md)。

# MCP 客户端接入

启动影院后，打开 **影院设置 → 连接 AI → MCP 客户端**。

1. 在 **名字与档案** 中选好这次要连接的观影 AI。
2. 在 **MCP 客户端** 页按需要勾选扩展权限（默认只提供观影与互动 4 个核心工具；可分别独立勾选“回查已播放的旧台词与声音 `--with-history`”和“控制影院 `--with-control`”）。
3. 选择你使用的客户端（Codex、Claude Desktop、Claude Code、Antigravity 或通用 MCP），网页会自动填入本机真实的 `mcp/server.mjs` 绝对路径，点 **复制配置** 贴进对应客户端并重启/刷新即可。
4. 观影前，点 **复制 Prompt** 取得中立的基础观影模板（其中的检查间隔会跟随「观影准备」的设置自动更新）。开始前先和 AI 确认好调用 `tick` 的频率，避免中途长时间不调用（隔太久会一次性积压大量画面与对白）；若中途真的落下了一大段，可以先暂停影片等 AI 对齐进度后再继续。你也可以先和 AI 沟通你喜欢的观影偏好与交流风格，再把模板发给它开始一起看。

也可以手动配置 MCP 客户端运行：

```text
node <项目文件夹>/mcp/server.mjs
```

需要额外工具时，在参数后按需追加 `--with-history` 或 `--with-control`（也可分别设置环境变量 `OPEN_WATCH_CINEMA_ENABLE_HISTORY=1`、`OPEN_WATCH_CINEMA_ENABLE_CONTROL=1`）。更多技术细节可把 [MCP 配置参考](../开发须知/MCP%20技术参考.md)和 [AI 观影说明](../../mcp/SKILL.md)交给 AI 或开发工具阅读。

在 ChatGPT 对话用影院卡片跟片时，按 [ChatGPT Listener](ChatGPT%20工具配置.md) 设置。

影院会记住上次选择。下次同一位 AI 来，连接后就能开始观影。两位同伴同时接入时，可对照下方[多位 AI 的署名示例](../观影须知/观影指南.md#多位-ai-一起观影)。已连上客户端但影院还没有档案时，回到设置添加并选中一位，再继续观影即可。

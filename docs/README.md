# 影院文档

这里是 Open Watch Cinema 的公开文档中心。如果你是第一次来，可以先按 [工具准备](#工具准备) 把环境和 AI 连接配好，再看 [观影须知](#观影须知) 熟悉片库、观影包和小本本；想了解实现细节、自己接模型或参与维护，直接看 [开发须知](#开发须知)。

## 观影须知

日常看片、管理片库和和 AI 互动的说明都在这里：

- [观影指南](观影须知/观影指南.md) · 从启动影院、导入试播、选字幕、跳过片头片尾、准备观影包，到开房同看、聊天互动、小本本手记、续看、导出与常见排错。启动影院后也能在网页「影院设置 → 观影指南」直接打开。
- [新版变化与升级指南](观影须知/新版变化与升级指南.md) · 给旧版用户看的功能变化、本机数据迁移、观影包升级和 AI 重连步骤。
- [观影包画质参考](观影须知/画质参考.md) · 同一镜头在经济、均衡和完整档的实际成品对比，拿不准该选哪一档时先看这篇。
- [新版变化与升级指南](观影须知/新版变化与升级指南.md) · 写给旧版老观众的变化总览、平滑升级步骤，以及让 AI 帮忙一键升级的现成提示词。

## 工具准备

装机依赖、排错，以及把不同的 AI 接进影院的方法：

- [安装与排错](工具准备/安装与排错.md) · macOS 和 Windows 安装步骤、复用已有 Python 环境、可选声音模型，以及常见安装排错。
- [ChatGPT 工具配置](工具准备/ChatGPT%20工具配置.md) · 在 ChatGPT 里接入影院应用、选择工具范围，用卡片自动跟片或在对话里主动读取。
- [Codex App Server](工具准备/Codex%20App%20Server.md) · 让影院把观影资料按播放进度自动送给本机 Codex，包含登录模式、开场白和续看说明。
- [MCP 客户端接入](工具准备/MCP%20客户端接入.md) · 配置 Codex、Claude Desktop、Claude Code、Antigravity 等支持本地 stdio MCP 的客户端。

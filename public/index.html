本机安装与配置

安装或更新 Codex 后，在上方读取账号和支持画面的模型。影院独立登录使用影院的数据目录。

npm install -g @openai/codex@latest

ChatGPT Listener 设置

在要一起看的 ChatGPT 对话中打开 Open Watch Cinema 卡片，再点卡片上的「开始观影」。两个开关都打开后，影院会随播放进度自动送来观影资料。开启此开关会将影院的自动连接方式切换为 ChatGPT Listener。

ChatGPT 工具范围

观影（基础工具） · 通过卡片跟片、在房间发言与互动、读写共用手记、重看已收到的分镜。

保存后，在 ChatGPT 的应用设置里对同一个 Open Watch Cinema 插件点 Refresh，以更新工具列表。

本机连接入口

为这个独立应用配置自己的 Secure MCP Tunnel。启动命令在项目根目录运行。

node watch-bridge/adapters/chat/main.mjs

应用接好后，在 ChatGPT 中打开 Open Watch Cinema。安装和首测步骤见项目内的 docs/工具准备/ChatGPT 工具配置.md。

给 AI 的工具范围

默认只提供观影和互动所需的基础工具（跟片、房间发言与互动、共享小本本、重看分镜图）。以下扩展按需勾选，修改后需重新复制配置并重启 AI 客户端。

客户端 MCP 配置

以上配置适用于支持本机 stdio MCP 的客户端。更多接入说明见 观影指南 与项目内的 docs/工具准备/MCP 客户端接入.md。
